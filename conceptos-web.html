📖 ¿Qué es un Sitio Web? (Entendiendo los conceptos)

A menudo usamos los términos informáticos de forma indistinta en el día a día, pero en el desarrollo profesional es crucial conocer la diferencia técnica exacta a través de una analogía muy simple:

La analogía del libro: Piensa en internet como una inmensa biblioteca global. Una "página web" es una hoja suelta de un libro que contiene información concreta, mientras que el "sitio web" es el libro completo encuadernado y estructurado con todas sus páginas conectadas.

💡 Qué es una página web

Es un documento o archivo electrónico único escrito en código de programación (principalmente HTML) capaz de contener texto, imágenes, vídeos, formularios y enlaces hipertextuales. Es la interfaz que visualizas en tu pantalla en un momento concreto bajo una dirección URL específica.

🗂️ Tipos de páginas web

Dependiendo de su comportamiento, funciones operativas y la tecnología con la que se procesan, las páginas se dividen principalmente en dos clases:

  • Páginas Estáticas: Muestran exactamente el mismo contenido predeterminado a todos los usuarios. No cambian ni interactúan con bases de datos a menos que un programador edite su código fuente directamente (por ejemplo, la landing page de presentación de una empresa o el menú digital fijo de un restaurante).
  • Páginas Dinámicas: Su contenido se genera en tiempo real adaptándose según las interacciones del usuario, sus preferencias o los datos guardados en un servidor (por ejemplo, el feed de publicaciones de Instagram, los carritos de compra de Amazon o los paneles meteorológicos automatizados).

🖥️ Qué es un sitio web

Es un espacio virtual centralizado en internet que agrupa un conjunto organizado de páginas web asociadas entre sí mediante enlaces de navegación y que comparten una misma temática o fin comercial. Para acceder a él, los usuarios utilizan una dirección principal única y fácil de recordar conocida como dominio (por ejemplo, www.wikipedia.org).

🌍 Cómo funciona Internet

Internet no es un ente mágico flotando en el aire; se trata de una red e infraestructura física colosal compuesta por ordenadores interconectados, centros de datos masivos y miles de kilómetros de cables de fibra óptica que envuelven todo el planeta compartiendo información de forma lógica:

🔎 El Modelo Cliente-Servidor

Toda la navegación web se basa en una arquitectura de petición y respuesta. El Navegador (como Google Chrome, Safari o Firefox) actúa como el cliente: es la aplicación que solicita ver una web. El Servidor es un ordenador de altas prestaciones encendido de forma ininterrumpida las 24 horas del día en algún lugar del mundo, encargado de almacenar de forma segura todos los archivos de la página web y enviárselos al cliente cuando este los solicita.

📡 El viaje técnico de los datos por la red

Al escribir un dominio, tu navegador no sabe a dónde ir, por lo que pide la dirección numérica del servidor a un traductor universal llamado DNS (que transforma nombres como google.com en códigos numéricos llamados direcciones IP). Una vez localizada la máquina, el archivo de la página web se fragmenta en millones de pequeños paquetes de datos.

Estos paquetes viajan por cables submarinos a la velocidad de la luz, toman rutas distintas para evitar colapsar la red y se vuelven a ensamblar perfectamente en el dispositivo del usuario para componer la interfaz final. Todo este trayecto se efectúa bajo el protocolo de seguridad cifrado HTTPS, asegurando que nadie intercepte la comunicación.
