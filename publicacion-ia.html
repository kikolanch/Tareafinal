🚀 Cómo subir tu web a Internet (Despliegue)

Una vez que has creado tus archivos HTML y CSS en tu ordenador, el siguiente paso indispensable es subirlos a un servidor en la nube para que cualquier persona del mundo pueda visitarlos. Para lograrlo de forma gratuita y profesional, utilizamos la plataforma GitHub.

Al guardar el código en un repositorio y activar la herramienta gratuita GitHub Pages, tus archivos se transforman automáticamente en un sitio web activo. El servidor se encarga de procesar los datos y te regala una dirección web pública que funciona bajo el protocolo seguro HTTPS.

🤖 El uso de la Inteligencia Artificial en el Desarrollo Web

Hoy en día, los programadores utilizan asistentes de Inteligencia Artificial (como ChatGPT o Codex) para acelerar el trabajo. En lugar de escribir cada línea de código desde cero o pasar horas buscando un fallo, puedes interactuar con la IA en lenguaje natural para que te ayude a dar forma a tu web.

La IA es excelente para sugerirte estructuras de etiquetas HTML, crearte reglas de diseño en CSS, corregir errores de visualización cuando algo no encaja bien y ayudarte a optimizar la página para que se adapte perfectamente a las pantallas de los teléfonos móviles.

🛠️ Guía Paso a Paso: Conectar GitHub con la IA de ChatGPT

  • Conexión del Entorno Remoto Iniciamos sesión en el entorno de ChatGPT y le damos acceso al repositorio de GitHub donde tenemos guardado nuestro proyecto web.
  • Escribir la Orden (Prompt) Escribimos con nuestras propias palabras los cambios o añadidos que queremos hacer en el diseño o el texto de la página.
  • Revisar los Cambios Propuestos El modelo procesa la petición y genera una propuesta con el código modificado. Hacemos clic sobre ella para examinarla en pantalla.
  • Crear la Solicitud de Cambios Si el código propuesto es correcto, pulsamos el botón interactivo situado arriba a la derecha: "Crea una solicitud de cambios" (Pull Request).
  • Acceder al Repositorio de GitHub Abrimos nuestra cuenta de GitHub en el navegador, entramos al proyecto y nos dirigimos a la pestaña de "Pull requests" para ver la solicitud enviada por la IA.
  • Fusionar el Código (Merge) Revisamos que todo esté en orden en el panel técnico y presionamos el botón verde brillante que dice "Merge pull request".
  • Publicación en Vivo Confirmamos la fusión pulsando "Confirm merge". El servidor de GitHub Pages compilará las modificaciones y, en un par de minutos, la web actualizada estará visible en Internet.
